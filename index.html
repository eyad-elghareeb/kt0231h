Analog PGA

0x3A / 0x3B

Analog input/output gain, selected by index. Semantics are vendor-confirmed on KT0211L / KT02H20 and read best-effort elsewhere — the KT0231H map puts its EQ table at these addresses.

Digital gain

0x65 / 0x66 · 0.5 dB steps

Signed byte, 0.5 dB per step. On stereo models register 0x66 holds DACL in byte0 and DACR in byte1; single-DAC parts ignore byte1.

Noise gate

0x71–0x73

Thresholds encode as byte = 256 + dB, so −60 dB is 0xC4 and −96 dB is 0xA0. The formula saturates one step below 0 dB, so the usable range stops at −1 dB (0xFF). Hold is fixed at 10 ms. Register layout decoded from the vendor desktop app on KT02H20.

Limiter

0x78–0x79

Register 0x78 carries EN in bit7 and SOFT in bit6; bit16+ holds the threshold byte. SOFT is the vendor app's soft-knee mode.

USB identity

0x40–0x5B

These edit the USB string descriptors the host shows. They live in run-mode RAM — replug to see them, and use Save to flash where the chip supports persistence. A VID/PID change re-enumerates the device, so record the current pair first.

Memory peek

0x08 · read-only

The 0x08 word reader answers from an extended space that most runtimes map to zeros. It cannot read flash, and it cannot modify the device. For a real backup see HARDWARE-DUMP.md.

Firmware image surgery

The vendor persistence path when a chip has no working SAVE command: take the unit's own image, rewrite the embedded EQ tables with the current bands, and flash it back. The EQ table is located by pattern, not by a hardcoded offset.

Compare two images

Which of two builds is which. Differences are grouped by what the bytes mean — a build-number edit and a re-tuned EQ are both "a few bytes changed" but call for opposite conclusions — so the verdict distinguishes them. This is how a re-badged firmware is told apart from a genuinely different one.

Bootloader flasher

31B2:0101 / 0001 / 0002

Put the dongle into bootloader mode, connect, and write a patched image you dumped from that same unit. Never flash a foreign BIN. The handshake is KTM → VER → KEY → CHP → CFG → PWO → KSTA, then 512-byte 0x69 blocks. Typing FLASH arms the write.

The unit re-enumerates as a CDC port once it is in boot mode, so connect after it has rebooted. Leave the base at 0 for the stock flag=0 images; the flag shifts the target by 32 KB per bit.

What is verified, and what is not

This tool talks to real hardware. The app never invents semantics: every control either comes from a vendor-confirmed register, a published reverse-engineering note, or is labelled best-effort.

  • EQ bands — byte-level confirmed on KT0211L, KT02H20, KT0210 and KT0231H.
  • Save to flash — vendor 0x53, user-verified on KT0211L and KT0210. Deliberately hidden on chips where it is unverified.
  • Digital gain — 0.5 dB steps, vendor-confirmed.
  • DRC registers — decoded from the vendor desktop app on KT02H20.
  • KT0231H PGA — unknown; those addresses hold EQ data on that chip.
  • Software firmware dump — proven impossible. The only real backup is hardware (SWD on GPIO4/5, or the UART bootloader on GPIO2/3).
